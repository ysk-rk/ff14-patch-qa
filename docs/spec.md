# 仕様書：FF14 パッチノート Q&A

最終更新: 2026-10-24

## 1. 目的

FINAL FANTASY XIV 黄金のレガシー（パッチ 7.0〜7.57）のパッチノートをもとに、質問に出典付きで答える。

パッチノートは、新しいパッチが古い内容を上書きしていく。このアプリでは、**古い情報を今の情報として答えないこと**を一番の品質目標にする。

## 2. 想定する利用者と使い方

- FF14 のプレイヤーが、スキルの今の性能や、いつ何が変わったかを調べる
- 質問例
  - 「モンクの万象闘気圏の今の威力は？」
  - 「PvPのモンクの夢幻闘舞は何が変わった？」
  - 「移動しながらマウントを呼び出せるようになったのはどのパッチ？」

## 3. 対象データ

| 項目 | 内容 |
| --- | --- |
| 取得元 | The Lodestone「パッチノート＆パッチ特設サイト一覧」 |
| 範囲 | 7.0、7.01、7.05、7.1、7.11、7.15、7.16、7.18、7.2、7.21、7.25、7.3、7.31、7.35、7.38、7.4、7.41、7.45、7.5、7.51、7.55、7.56、7.57（23本） |
| 言語 | 日本語 |
| 公開 | 本文は公開しない。GitHub には取得スクリプトと元記事へのリンクだけを置く |

## 4. 機能

### 4.1 質問に答える

- 利用者が日本語で質問を入力する
- パッチノートから関連する箇所を検索し、AI が回答を作る
- 回答には、根拠にしたパッチ番号を必ず含める

### 4.2 回答のルール

| ルール | 内容 |
| --- | --- |
| 資料だけで答える | 資料に書かれていないことは答えず、「パッチノートからは分かりませんでした」と答える |
| 新しい情報を優先する | 同じ項目が複数のパッチで変わっている場合は、一番新しいパッチの値を今の値として答える |
| PvE と PvP を区別する | 質問に PvP と書かれていなければ PvE として答える |
| 出典を示す | 根拠にしたパッチ番号を書く |

### 4.3 出典を表示する

- 回答に使った資料を、新しいパッチが上に来る順で表示する
- それぞれに、パッチ番号、PvE／PvP のラベル、見出し、元記事へのリンク、検索の近さを表示する
- 回答したモデル名を表示する

## 5. API

### POST /ask

リクエスト

```json
{ "question": "モンクの万象闘気圏の今の威力は？" }
```

レスポンス（200）

```json
{
  "answer": "モンクの「万象闘気圏」の現在の威力は 160 です。（根拠: パッチ7.2）",
  "model": "gemini-3.8-flash",
  "sources": [
    {
      "version": "7.2",
      "headings": "バトル関連 > アクション／特性において、以下の調整が行われます。 > モンク",
      "url": "https://jp.finalfantasyxiv.com/lodestone/topics/detail/…/",
      "score": 0.836
    }
  ]
}
```

| フィールド | 内容 |
| --- | --- |
| answer | AI の回答 |
| model | 回答したモデル |
| sources | 回答に使った資料（パッチの古い順） |
| sources[].version | パッチ番号 |
| sources[].headings | 見出しの階層（「 > 」区切り） |
| sources[].url | 元記事の URL |
| sources[].score | 質問との近さ（0〜1） |

エラー

| コード | 場合 |
| --- | --- |
| 422 | リクエストの形が正しくない |
| 503 | すべての AI モデルが混雑や回数制限で使えない（detail に理由を入れる） |

## 6. 評価

### 6.1 評価用データ

`eval/questions.jsonl` に1行1問で置く。現在20問。

| フィールド | 内容 |
| --- | --- |
| id | 問題の ID（q001〜） |
| question | 質問文 |
| mode | pve / pvp / general（バトル以外）/ none（答えられない） |
| kind | 質問の種類（下の表） |
| expected | 正解 |
| as_of | どのパッチ時点の正解か |
| latest_patch | その項目が最後に変わったパッチ |
| keyword | 根拠の資料に含まれているはずの言葉 |
| evidence_versions | 正解を答えるのに必ず必要なパッチ |
| note | 変更の流れなどのメモ |

| kind | 内容 | 問題数 |
| --- | --- | --- |
| latest | 一番新しい変更がそのまま正解 | 10 |
| other_attr_later | 後のパッチで別の項目だけが変わっている | 5 |
| pvp_noise | PvP の調整が混ざりやすい | 1 |
| history | 変更の流れ全体を答える | 1 |
| when | いつ変わったかを答える | 1 |
| unanswerable | 答えられないことを正しく伝える | 2 |

正解の決め方: パッチごとの「変更前」と「変更後」の数字がつながっているかで確かめる。間に見落とした調整があれば、ここがずれる。

### 6.2 評価の指標（2週目に実装予定）

| 指標 | 内容 |
| --- | --- |
| 検索の再現率 | evidence_versions のパッチで keyword を含む資料を、検索で拾えた割合 |
| 回答の正解率 | expected と回答の数字が合っている割合 |
| 今の値として答えた割合 | 変更の一覧ではなく、今の値として答えた割合 |
| 古い値で答えた割合 | latest_patch より前の値で答えた割合 |
| 答えられない質問への対応 | unanswerable の質問で「分からない」と答えた割合 |

指標は kind ごと、モデルごとにも集計する。

## 7. 制約

- AI は Gemini API の無料枠で使う。混雑（503）や回数制限（429）が起きる
- 無料枠に送った内容は Google のサービス改善に使われることがある。公開されているパッチノート以外の情報は送らない
- パッチノートの著作権はスクウェア・エニックスにある。本文は公開しない
- 新しいパッチは自動では取り込まない（今後の作業で対応）

## 8. 今はやらないこと

- 7.0 より前（暁月のフィナーレ以前）のパッチ
- パッチノート以外の情報（攻略サイト、遊び方の解説など）
- ログインなどの利用者管理
